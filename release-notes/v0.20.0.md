**HybridSliceCraft 0.20.0** gives the window a title bar that fits each desktop, remembers where the window was, and colours focus and selection to match filament or resin mode.

## New

- **A title bar that fits your desktop.**
  - On GNOME, KDE and Windows the program draws its own title bar, with window buttons in that desktop's style and order. On macOS the traffic lights sit over the program's bar.
  - On tiling desktops such as Sway or Hyprland the system's frame stays.
  - Minimize, maximize and close are always there, even where the desktop shows only close.
  - **View → Use system title bar** gives the title bar to the system from the next start. `HYBRIDSLICECRAFT_TITLEBAR=system` (or `=app`) chooses for one run.
- **The window opens as you left it:** same size, same place, maximized or not. On Wayland the place is left to the desktop.
- **View → Language → System language** follows the system's language. This is now the default.

## Better

- **Follow system** switches between light and dark as soon as the system does.
- **Colours.** Focused fields, the selected row of a drop-down and selected text are amber in filament mode and teal in resin mode.
- **Light theme.**
  - Text fields always have a border.
  - Selected tabs, plates and the Filament/Resin and Prepare/Preview switches are in full colour.
- **Settings file.** The settings are now kept in `config.toml`, with a backup, in the same folder as before. The old `preferences.json` is read once and left in place.
- **Pictures.** All pictures in the manual are new, and one shows the light theme.

Printer instructions for the same model and settings are exactly the same as in 0.19.0.
