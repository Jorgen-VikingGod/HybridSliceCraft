**HybridSliceCraft 0.7.0** lets you choose a different filament for each part of a model, as OrcaSlicer does.

## A filament for each feature

On a printer with more than one filament slot, the "This model only" panel now has a filament choice for each of these:

- **Filament**: the outer walls, and everything not set below
- **Inner walls**
- **Infill with**: the sparse infill
- **Solid infill**: the top, bottom and bridge skins, and ironing
- **Support**
- **Support interface**: follows the support unless you choose another filament

You could use a different colour for the inner walls, a cheaper filament for the infill, or a soluble or flexible one for the support interface. A layer is printed one tool at a time, and each pass prints only what that tool is set for. Painted colours still print everything of their piece. The choices are saved in project files.

Prints that use only one filament produce exactly the same G-code as before.

## Good to know

- Line widths follow the nozzle of the model's main filament. Only the sparse infill adjusts to its own nozzle size.
- Spiral vase mode prints with the main filament only.
- Using many different filaments within one layer means many tool changes, so the print takes longer.

None of the saved files have been tried on a real printer yet. Check a small print first.
