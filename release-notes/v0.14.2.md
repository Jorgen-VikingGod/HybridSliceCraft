**HybridSliceCraft 0.14.2** fixes the AppImage.

## Fix

- The AppImage did not start on systems without libxkbcommon-x11 ("Library libxkbcommon-x11.so could not be loaded"). The window code loads this and a few other X11 libraries by itself, so they were not packed. They are now inside the AppImage, and every release starts the AppImage the way the AppImage catalogue tests it. The program itself is the same as 0.14.0.

None of the saved files have been tried on a real printer yet. Check a small print first.
