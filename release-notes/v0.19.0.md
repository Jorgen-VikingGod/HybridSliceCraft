**HybridSliceCraft 0.19.0** gives the program menus that behave like other desktop programs', and signs the Linux downloads.

## Better

- **Menus** look and work like a desktop program's:
  - Each item's shortcut is shown in its own column on the right (Ctrl+S, or ⌘S on a Mac), and changed shortcuts show up there too.
  - Once a menu is open, moving the pointer onto another menu's title opens that one. No extra click is needed.
  - Submenus (Mirror, Theme, Language) open when you rest on them. You can also press on a title, move to an item and let go.
  - The keyboard works as elsewhere: ↑ ↓ ← → move, Enter runs an item, Esc closes. Alt or F10 puts the keyboard on the menu bar, and Alt with a letter opens a menu.
  - Highlight overhangs, the current theme and the current language are marked with a dot. Items that can't be used now (Duplicate, Delete or Mirror with nothing selected, Undo with nothing to undo) are greyed.
  - The program's own shortcuts wait while a menu is open.
- The button that puts a changed setting back to the preset's value showed as an empty box. It is now a proper icon.

## Downloads

- Each release now has a `SHA256SUMS.txt` with the checksum of every installer, signed with the project's release key. The `.deb`, AppImage and `.zsync` have their own signatures (`.asc`). The key is attached as `release-signing-key.asc`, and its fingerprint is in the README:

      gpg --import release-signing-key.asc
      gpg --verify SHA256SUMS.txt.asc SHA256SUMS.txt
      sha256sum --check --ignore-missing SHA256SUMS.txt

- The Windows and macOS installers are still not code-signed, so Windows SmartScreen and macOS Gatekeeper still warn on first launch.

Printer instructions for the same model and settings are exactly the same as in 0.18.0.
