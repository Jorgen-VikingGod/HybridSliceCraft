**HybridSliceCraft 0.12.0** lets AI agents use the slicer.

## An MCP server for AI agents

Start the program with `hybridslicecraft --mcp` and it runs as an MCP server (Model Context Protocol). It has no window and talks over standard input and output, so an assistant such as Claude, or any program that supports MCP, can slice models for you.

The agent gets these tools:

- **list_catalog**: the printers, filaments, resins and print profiles, including your own and imported ones.
- **describe_settings**: every setting by name, with its default and the allowed values of choice settings.
- **inspect_model**: size, volume, triangle count and whether a model is solid and watertight.
- **slice_filament**: slices models, or a ready-made calibration model, for a filament printer and writes the G-code. It reports print time, filament use, cost and warnings.
- **slice_resin**: slices models for a resin printer and writes an SL1, PNG zip, CTB, GOO or Anycubic file. It can add supports, hollow the model and add a drain hole, and reports resin use, floating parts and trapped resin.
- **render_layer**: a picture of one layer of a finished slice. Filament layers are drawn from above with the line types coloured, and resin layers as the exposure picture.

The manual is also offered to the agent, so it can look up how a feature works.

Settings are changed by name, for example `{"walls": 4, "infill_pattern": "Gyroid"}`. A wrong name or value comes back as a message that says what is allowed, so the agent can correct itself.

## Setting it up

Add the program as a server in your agent program's settings. For programs that read a `mcpServers` list:

```json
{
  "mcpServers": {
    "hybridslicecraft": { "command": "hybridslicecraft", "args": ["--mcp"] }
  }
}
```

For Claude Code: `claude mcp add hybridslicecraft -- hybridslicecraft --mcp`. The manual has more examples and tips.

## Good to know

- The server reads and writes only the files the agent names, and it sends nothing to a printer. The agent gets the file and you decide what to do with it.
- The Flatpak can't see files outside its sandbox, so use the `.deb`, AppImage, `.msi` or `.dmg` for agents.
- The server has been tested by speaking the protocol directly; it has not yet been tried with every agent program. Tell us if one of them has trouble.

None of the saved files have been tried on a real printer yet. Check a small print first.
