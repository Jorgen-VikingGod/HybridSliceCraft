The first release of **HybridSliceCraft**: one slicer for filament (FDM) and resin (MSLA) 3D printers, with a fast 3D view drawn by the graphics card.

Author: Jürgen Könnemann

## Filament (FDM)

**Walls and surfaces**
- Walls with thin-wall detection and gap filling between walls
- Top and bottom skins in monotonic, zig-zag or concentric patterns
- Bridges laid across the shortest span, with their own speed, flow and full cooling
- Overhang detection: overhanging walls print slower with extra cooling
- Seam placement: aligned (hidden in corners), nearest, back or random, with a seam gap
- Ironing for smooth tops, and fuzzy skin for a textured finish
- Size correction and elephant-foot correction on the first layer

**Infill**
- Ten patterns: grid, lines, rectilinear, triangles, cubic, gyroid, honeycomb, concentric, cross hatch, and lightning-style
- Each model can have its own infill density, wall count and flow

**Supports and adhesion**
- Grid supports and tree supports, with dense interface layers and adjustable gaps
- Optional "only from the plate" supports
- Skirt, brim and raft

**Speed, cooling and output**
- Per-feature speeds and accelerations, with a melt-rate limit per filament
- Cooling that slows short layers and sets the fan from layer time
- Time estimates that account for acceleration and cornering, per-feature time breakdown, filament weight and cost
- Arc fitting (G2/G3), pressure advance, relative or absolute extrusion
- Marlin, Klipper and RepRapFirmware output, with editable start, end and tool-change scripts
- Built-in printer previews (thumbnails) in the G-code

**Several filaments and nozzles**
- Several filaments in one print, with a prime tower that places itself clear of the parts
- **Several nozzle sizes in one print**: each tool can have its own nozzle (for example 0.4 mm and 0.8 mm). Each model's lines follow the size of the nozzle that prints it, and a model can print its walls with the fine nozzle and its infill with the big one.
- One object at a time, or everything layer by layer

**Special modes and tests**
- Spiral vase mode and adaptive layer heights
- Calibration tests: temperature tower, flow test, retraction test, pressure advance tower, first-layer test

**Preview and sending**
- Layer range and move-by-move scrubbing with playback
- Colour by line type, speed, flow, layer height, line width, fan, temperature, layer time or filament
- Show or hide each line type
- Send G-code to OctoPrint or Moonraker (Klipper) printers over the local network

## Resin (MSLA)

**Supports**
- Automatic supports that find every part that would start in mid-air, plus shallow down-facing surfaces
- Thin pinhead tips with a shallow contact depth, so supports snap off cleanly
- Every support is kept clear of the model along its full length; supports only stand on the model where a part would otherwise fall off
- Branches that share pillars, cross-bracing for tall pillars, and a raft
- Add or remove supports by hand

**Hollowing and drainage**
- Hollowing with a chosen wall thickness and an optional inner lattice for strength
- Drain holes placed by hand or at the lowest point
- A check that warns about resin trapped inside the print
- Cut-through view to inspect walls and cavities

**Layers and checks**
- Edge smoothing (anti-aliasing up to 8×), bottom and transition layers, elephant-foot correction
- A check that marks any part starting in mid-air, layer by layer
- Layer picture viewer with zoom, a lit-area chart, print time, resin volume, weight and cost
- Layers drawn on the graphics card or the processor, whichever is faster, timed on each print

**Output**
- SL1 (a zip of layers plus settings), a PNG layer stack (zip), and unencrypted CTB

## For both

- Opens STL, OBJ, 3MF and PLY files, repairing common faults on import
- Move, turn and resize handles, lay a face flat, cut, split, mirror, auto-orient and arrange
- Several plates, undo and redo, project files, your own saved presets
- Built-in profiles for common printer types, filaments and resins, all editable
- Starter model to try straight away

## Installers

| System | File |
| --- | --- |
| Windows | `.msi` installer |
| macOS, Apple silicon and Intel | `.dmg` disk image (one for each chip) |
| Linux | `.deb` package and a portable `.AppImage` |

The installers aren't code-signed yet. Windows SmartScreen and macOS Gatekeeper will warn on first launch; on macOS, right-click the app and choose Open.

## Known limits in this first release

- Files haven't been tried on real printers yet. Start with a small print, especially with the CTB format.
- Not included yet: brush-painting colours onto a model, live printer camera and control, encrypted resin formats (needed by some newer resin printers), and cloud model libraries.
- Printing with two nozzle sizes relies on the printer's firmware handling each tool's offsets, as tool changers and IDEX printers do.
