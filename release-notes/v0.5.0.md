**HybridSliceCraft 0.5.0** adds painting with several filaments and presets for the Snapmaker U1.

## New for filament printing

**Paint with filaments**
- A new Paint tool: pick a filament, then drag over the model to paint it. The brush size is adjustable.
- **Fill** colours a whole face or smooth patch at once and stops at sharp creases. **Erase** takes paint off. **Paint everything** and **Clear paint** work on the whole model.
- **Colour reaches in** sets how far a painted colour goes into the part. Top and bottom surfaces colour the layers next to them too.
- Each colour prints with its own filament, using the prime tower for tool changes. Paint is saved in project files.
- Painting needs a printer with more than one filament slot, such as the dual extruder, the four-colour changer or the Snapmaker U1.
- Where two colours meet, each side prints its own wall. Repair clears the paint on a model.

**Snapmaker U1**
- Five printer presets: 0.2, 0.4, 0.6 and 0.8 mm nozzles on all four heads, and a mixed 0.4 + 0.6 mm one.
- Start and end scripts come from OrcaSlicer's profile for this printer and use the U1's own macros.
- Scripts can now use `{nozzle_temp-50}` and `{nozzle_temp-90}`.
- The pre-extrude step after each tool change isn't included; the prime tower does the purging.

## Other

- The README pictures are refreshed, and pictures taken with `--screenshot` no longer catch a stray tooltip.
- A saved project can be opened from the command line.

None of this has been tried on a real printer yet. Check a small print first.
