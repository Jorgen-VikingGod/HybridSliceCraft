**HybridSliceCraft 0.22.0** gives the window the look and menus of the other Craft apps, and a new keyboard shortcut list.

## New

- **Keyboard shortcuts, one key at a time.** **Help → Keyboard shortcuts** lists each command with its keys. Click a key and press the new one to change it, or click **+** to give the command one more key. The curved arrow puts the command's usual keys back, **×** leaves it without a key, and **Reset all** puts every key back. Combinations such as Ctrl+Shift+F are recorded whole.
- **Right-click menus like the menu bar.** The menu of a model or the plate, and the menu of a card's title, look and work like the menus in the menu bar, with submenus and the arrow keys. The model's menu shows each command's key.
- **Driving the window from scripts.** Started with `HYBRIDSLICECRAFT_CONTROL_PORT=0`, the program accepts clicks, keys, menu choices and requests for pictures of the window from scripts on the same computer. It is off unless you set it. `docs/automation/control.py` shows how.

## Better

- **The look of the other Craft apps.** The interface uses the Craft apps' font, and the menus share their behaviour: **F10** or **Alt** goes to the menu bar, **Alt** and a letter opens a menu, and **Escape** closes an open menu.
- **Project and resin files are the same every time.** Saving the same plate twice now gives exactly the same file.
- "Move to the right panel" and "Move to the left panel" in a card's menu are translated now.

Printer instructions for the same model and settings are exactly the same as in 0.21.1. Resin files hold the same layers and settings; only the date stored with each part of the file changed.
