**HybridSliceCraft 0.14.1** fixes the AppImage.

## Fix

- The AppImage's start file could only be run by its owner, so running the AppImage as another user, or inside a sandbox, failed with "Permission denied". The release now opens the permissions inside the AppImage and checks them. The program itself is the same as 0.14.0.

None of the saved files have been tried on a real printer yet. Check a small print first.
