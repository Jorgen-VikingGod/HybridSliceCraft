**HybridSliceCraft 0.7.1** makes line widths follow the nozzle of the tool that prints each part of a model.

## Line width follows the nozzle

On a printer with different nozzle sizes per tool, the lines of each feature now get their width from the nozzle of the tool that prints it:

- outer walls
- inner walls and gap fill
- solid infill (top, bottom and bridge skins, and ironing)
- sparse infill
- support
- support interface

For example, you can print the outer wall with a 0.4 mm nozzle for detail, and the inner walls, infill and support with a 0.6 mm nozzle for strength and speed. Set the nozzle size of each tool in the printer settings ("Nozzle, tool 1", "Nozzle, tool 2" and so on), then choose the filament for each feature in the model's "This model only" panel.

Before this, only sparse infill used its own tool's nozzle size; everything else followed the model's main filament.

Prints that use one nozzle produce exactly the same G-code as before.

## Good to know

- Skirt, brim and the prime tower still use the main tool's line width.
- Spiral vase mode prints with the main filament only.

None of the saved files have been tried on a real printer yet. Check a small print first.
