**HybridSliceCraft 0.16.0** makes cutting more flexible, lets you merge models, and checks for updates.

## New

- **Check for updates** (#78). Help → Check for updates… finds the newest release. The AppImage replaces itself, Windows starts the new installer, macOS opens the new disk image; the `.deb` and Flatpak show how to update. The program also looks once at start, quietly, and tells you only when there is something new; you can turn that off. It asks GitHub for the newest release and sends nothing else.
- **Merge into one** (#84). Edit → Merge into one joins the selected models into one, right where they are. Paint and supports come along; *Split into parts* takes it apart again.
- **Save selection as STL** (#84). File → Save selection as STL… saves only the selected models, as one file.

## Changes

- **The cut tool** (#85) cuts across X, Y or Z, at any position, and cuts several selected models at once. It no longer re-arranges the plate: only the pieces move. *Lay the cut faces on the plate* and *Find room for the pieces* can each be turned off; then the pieces stay where the model was, just apart. The upper half of a horizontal cut now stays upright instead of being turned upside down.

Updating from inside the program starts with this version, so this one more update is by hand.

None of the saved files have been tried on a real printer yet. Check a small print first.
