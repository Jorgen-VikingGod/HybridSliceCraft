**HybridSliceCraft 0.10.0** opens STEP files and fixes two problems reported by users.

## STEP files

Models saved as STEP (.step, .stp), the format most CAD programs export, can now be added to the plate like any other model. The exact surfaces are cut into fine triangles, so curved parts come out round, and the file's length unit (millimetres, centimetres, metres or inches) is converted to millimetres.

Not every STEP file can be read yet. Some use kinds of surfaces the reader doesn't know. When that happens the program tells you so instead of failing quietly; exporting the part as STL or 3MF from your CAD program works as before. A file that holds only surfaces and no solid is reported as such.

## Fixes

- **Pasting works.** Text copied in another program can now be pasted into the program, for example a start script in the printer settings. Before, only text copied inside the program could be pasted.
- **No extra window on Windows.** The black command window that opened beside the program is gone, so closing it can no longer close the slicer. Started from a terminal, the program still prints there.

None of the saved files have been tried on a real printer yet. Check a small print first.
