**HybridSliceCraft 0.18.0** opens glTF, GLB and FBX models and makes saving and file dialogs more robust.

## New

- **glTF (.gltf, .glb) and FBX models** can be added to the plate, by Add models or by dropping them on the window. They are converted to millimetres with Z up, so they arrive the right size and the right way up.
- A model whose file name has the wrong ending (for example a 3MF or GLB saved as `.stl`) now opens anyway: the file's content decides what it is.

## Better

- **Saving is safe against interruptions.** G-code, projects, resin files, STL, pictures and your settings are written to a hidden file first and only replace the old file once they are complete. A crash, a full disk or a cancelled export leaves the previous file as it was.
- Settings, the session and custom profiles are saved readable only by you.
- **File dialogs no longer freeze the window** while they are open. This also avoids a crash on macOS when a file was dragged over the window during a dialog.
- On Linux the file-type filters also show files with upper-case endings, like `MODEL.STL`.
- Damaged or oversized project files, preset bundles and 3MF files are refused with a message instead of filling the memory.
- Closing the window quits the program the way macOS expects.

## For AI agents (MCP)

- The server now rejects arguments a tool doesn't know, instead of ignoring them. All arguments the tools read are listed in their schemas.

## Under the hood

Saving, model import, ZIP reading, the MCP server and the file dialogs now come from the shared [craft-libs](https://github.com/storytold/craft-libs) crates. Printer instructions for the same model and settings are exactly the same as in 0.17.0.
