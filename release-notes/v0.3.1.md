**HybridSliceCraft 0.3.1** adds saving for Anycubic printers, a ready-made list of Elegoo and Anycubic machines, and two new ways to install on Linux.

## New for resin printing

**Save for Anycubic printers**
- A new save format, Anycubic Photon Workshop, writes the files these printers read: `.pwmx`, `.pwmb`, `.pm5s`, `.pm3n` and 17 more types.
- The file type is picked from your printer. With the command line, `--export print.pm5s` chooses it by extension.
- It hasn't been tried on a real printer yet. Start with a small test print.
- The newest Anycubic models (Photon Mono M7 and M7 Pro, Mono 4 Ultra, Photon P1 and P1 Max) use a different file type that isn't supported yet. For those, save as SL1 and convert it with UVtools; the program shows a note when you pick one.

**47 Elegoo and Anycubic printers**
- Mars, Saturn and Jupiter from Elegoo, and Photon, Photon Mono, M-series and P-series from Anycubic are in the printer list, with their real screen size, build volume and screen mirroring.
- Picking a printer also picks the file type it reads.
- The data comes from the Open Resin Alliance's printer profiles.
- Many Elegoo models (for example Mars 3, Saturn 2 and Saturn 3) expect a newer, encrypted CTB file that this program can't write yet, and the Jupiter 2 expects GOO version 5.1. Check what your printer accepts before a long print.

## Installing on Linux

- **Debian and Ubuntu:** a signed apt repository, so the program updates with the rest of your system. The commands are in the README.
- **Flatpak:** the files for Flathub are in the project. Flathub itself isn't available yet.

## Known limits

- The Anycubic and GOO formats haven't been tried on real printers.
- The German, French and Spanish texts haven't been reviewed by native speakers.
- The Windows and macOS installers still aren't code-signed.
