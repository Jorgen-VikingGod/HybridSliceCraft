**HybridSliceCraft 0.15.0** follows the system's theme and makes the AppImage updatable.

## Changes

- **The theme follows the system.** The new choice *Follow system* in View → Theme is the default: the program starts light, and dark when the system is set to dark mode. *Dark* and *Light* are still there, and a theme you picked before is kept.
- **The AppImage can update itself.** It now says where its updates come from, and each release has a `.zsync` file next to it. AppImageUpdate (or a tool like it) then downloads only what changed.

None of the saved files have been tried on a real printer yet. Check a small print first.
