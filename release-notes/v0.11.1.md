**HybridSliceCraft 0.11.1** adds a manual and tidies up the program's code. Nothing changes in the G-code it writes.

## A manual

There is now a manual that explains every feature, with pictures taken from the program, examples and hints. It has a section for filament printers and one for resin printers, and one subsection for each feature: from preparing the plate, supports, infill and painting with filaments to mixed filaments, hollowing, drain holes and the resin preview. You find it in the program's repository, in the file docs/manual.md, and the README links to it.

## Under the hood

- All build warnings are gone, and two outdated libraries that Rust warned about for a future version are no longer used. They came from a file-writing feature of the STEP reader that the program never needed.
- A few options for the command line set the window up with a given tool, settings tab, dialog or colouring, which is how the manual's pictures were made. `hybridslicecraft --help` lists them.

None of the saved files have been tried on a real printer yet. Check a small print first.
